# Google Analytics Event Tracking

The project includes a helper module to facilitate the integration of Google
Analytics (GA) event tracking. This helper, called gtag, makes it simple to
create GA events in a modular way. With this setup, you can easily track
interactions on each section.

[Initializing analytics](/_js/core/analytics/)
