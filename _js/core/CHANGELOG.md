Changelog
=========

All notable changes to the core modules should be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/).

2025W20
-------

### Added

- Add `findOneElementOfType` DOM helper to narrow element types in Typescript easily
- Add `ImplementationError` custom error

### Changed

- Move `findSiblings` DOM helper into a separate module
- Improve readability of ShopifyRoot parsing

2025W15
-------

### Changed

- Improve Wizard logic engine
- Improve parsing of Shopify network error response

2024W45
-------

### Added

- Allow removing individual event listeners without destroying the entire event namespace

2024W44
-------

### Added

- Add controls to specify product options that customers must select before
  adding to the cart

2024W43
-------

### Changed

- Allow EventTarget type as input for isHTMLElement

2024W40
-------

### Added

- Universal parsing schema for Shopify GIDs and legacy IDs
